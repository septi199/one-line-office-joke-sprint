Entry for the [make.fun](https://make.fun/?ref=xaqxgz17) bounty **One-Line Office Joke: 24-Hour Sprint** ($2, top 8 places).

The program writes one joke (118 characters) to `/output/entry.txt`:

> Our team building exercise was a trust fall. Nobody caught anyone, but the spreadsheet documenting it has 14 tabs now.

Run it with `node main.ts` (Node 22+ runs the TypeScript as-is). The output is deterministic: the same bytes on every run.
